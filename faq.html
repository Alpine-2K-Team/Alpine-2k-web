FAQ

Everything you wanted to ask about Alpine.2K — short answers.

What is Alpine.2K?

Alpine.2K is a homebrew app for modded consoles. Install it once on your console, and it becomes an app store — browse and download releases for that console, straight from the Alpine.2K GitHub repo for that system.

Which consoles are supported?

Currently: PS5, PS4, PS3, Xbox, Xbox 360, Nintendo DS, and Wii. Each has its own Alpine.2K repo. More consoles will be added over time.

Is Alpine.2K legal?

Yes. Alpine.2K only distributes content that's legally acquired, freely distributed, or your own homebrew. We do not host or link to pirated games, ROMs, or ISOs. See legal for the full disclaimer.

Where do the downloads come from?

Every release is published to that console's GitHub repo (Alpine-2K-Ps5, Alpine-2K-Ps4, etc.). The website reads those repos live, so a new release shows up on the site within a few minutes.

How do I install Alpine.2K on my console?

Mod your console first (CFW, HEN, RGH, JTAG, Homebrew Channel, etc.), then download the latest Alpine.2K release for your console from its repo and install it with your homebrew loader. Guides are in the Guides section.

Does Alpine.2K cost anything?

No. Alpine.2K is free and MIT-licensed. If you'd like to support development, head to the Donate page — but it's never required.

Can I request a release or a new console?

Yes. Open an issue on the relevant console repo (or on the website repo) using the appropriate template. We review everything.

Will modding brick my console?

Modding carries risk. Alpine.2K releases are tested, but you should always back up your console first. Follow the guides exactly and never disconnect power during flashing.

One repo per console. One app for everything.
