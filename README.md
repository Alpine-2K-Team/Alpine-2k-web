## How to deploy
1. Push all files to `main`
2. Settings → Pages → Source: **Deploy from a branch**
3. Branch: **main** · Folder: **/ (root)**
4. Save, wait 1–2 min, refresh your Pages URL

## Local preview
Just open `index.html` in your browser. No build step needed.
