# 🏔️ Alpine.2K

**The homebrew app for modded consoles.** Install once, download real — legally acquired — games and homebrew directly on your console.

## Live site
https://alpine-2k.github.io/alpine-2k-web/

## Pages
- `index.html` — Home
- `store.html` — All releases from every console repo
- `consoles.html` — Console list
- `console.html` — Single console page (`?id=ps5` etc.)
- `download.html` — Download the Alpine.2K app
- `guides.html` — Guides index
- `news.html` — News feed
- `faq.html` — FAQ
- `donate.html` — Donations
- `contact.html` — Contact
- `about.html` — About
- `legal.html` — Disclaimer

## Deploy
1. Push all files to `main`
2. Settings → Pages → Source: **Deploy from a branch**
3. Branch: **main** · Folder: **/ (root)**
4. Wait 1–2 min
